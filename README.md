# TITAN — Landing de gimnasio

Landing en español con estética futurista sobria, tonos grafito y salvia, ilustración metálica original, programas, enfoque de entrenamiento, video de YouTube y selector interactivo de objetivos. Adaptable a móviles.

`index.html` es autocontenido: incluye estilos, JavaScript e ilustraciones. Se puede abrir directamente y compartir sin archivos auxiliares. El video requiere conexión a YouTube; incluye un enlace directo como alternativa.

Los archivos `styles.css`, `script.js` y `assets/gym.svg` conservan las fuentes de edición. Si los cambias, actualiza también el contenido integrado en `index.html`.

Para servir el proyecto localmente:

```sh
cd /workspace/repo-codex
python -m http.server 3000 --bind 0.0.0.0
```

TITAN es una marca de muestra. No hay reservas, tarifas ni envío de datos.
